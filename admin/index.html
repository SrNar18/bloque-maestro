Configurar acceso al panel

El panel guarda los cambios en el repositorio de GitHub. Para ello necesita un token de GitHub que se guarda cifrado con la contraseña: sin la contraseña no se puede usar.

  1. Abre GitHub → Fine-grained tokens → Generate new token.
  2. En Repository access elige Only select repositories y marca .
  3. En Permissions → Repository permissions pon Contents: Read and write. Nada más.
  4. Elige la caducidad que quieras, genera el token y pégalo aquí.

Usa una contraseña larga (10 caracteres o más). Si ya había un usuario con ese nombre, se sustituye.
